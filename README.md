# Abartılı Merhaba Dünya Üreticisi

## Bu Nedir?

Bu, insanlık tarihinin en önemli yazılım projelerinden biridir. "Merhaba Dünya" demek artık sıradan bir iş değil. Bu program, o basit selamı öyle bir abartır ki, evrenin kendisi utancından kızar.

## Özellikler

- **Gerçekten çalışır**: Python 3 ile uyumlu.
- **Dramatik bekleme süreleri**: İnsanın sabrını test eder.
- **Rastgele ciddi giriş cümleleri**: Her çalıştırışta farklı bir abartı.
- **5 kez tekrar**: Çünkü bir kez yetmez.
- **Hiçbir işe yaramaz**: Bu özellik kasıtlıdır ve gurur duyulur.

## Nasıl Çalıştırılır?

```bash
python3 merhaba.py
```

Veya yetki verip:

```bash
chmod +x merhaba.py
./merhaba.py
```

## Uyarı

Bu programı çalıştırdıktan sonra hayatınızda hiçbir şey değişmeyecektir. Eğer değişirse, bu tamamen sizin hayal gücünüzdür. Lütfen abartmayın, zaten program abartıyor.
